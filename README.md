# Book Tracker
**Автор:** Элина Асланова
## Описание
Приложение для учёта прочитанных книг. Позволяет добавлять книги, фильтровать их по жанру и количеству страниц, сохранять данные в JSON-файл.
## Установка и запуск
1. Установите Python 3.7+
2. Скачайте файл `main.py`
3. Запустите программу:
   ```bash
   python main.py
